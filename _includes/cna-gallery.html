{%- comment -%} cna-gallery — event photo mosaic. Renders page[include.id] as a fixed 3-column grid and pads the last row with flat filler tiles, so every event block is a full rectangle regardless of how many photos it has. The first photo spans 2x2, which both gives the block a lead image and keeps the remaining thumbnails from shrinking to nothing on a phone. Thumbnails are cropped (object-fit: cover); the uncropped photo is shown by the lightbox in footer/custom.html. Cell budget: a 2x2 lead eats 4 cells instead of 1, so cells = (n - 1) + 4. Fillers top that up to a whole number of rows.
